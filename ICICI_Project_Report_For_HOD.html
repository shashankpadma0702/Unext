Project Technical Report

ICICI UNext Financial News Dashboard

Prepared for Department Review

1. Executive Summary

The ICICI UNext Financial News Dashboard is a custom-built, full-stack web application designed to aggregate and deliver real-time financial market data, business news, and localized ICICI Bank updates. The goal of this project was to create a high-performance, resilient platform that offers a premium, modern interface with advanced capabilities like interactive data visualization and AI-driven content summarization capabilities.

2. Technology Stack

The application follows a modern React + Node.js (MERN without the Database) architectural pattern. The stack comprises:

  • Frontend Base: React 19, powered by Vite for blazing-fast Hot Module Replacement (HMR) and optimized production builds.
  • Frontend Data Fetching: Axios HTTP client component for handling REST API requests to the backend.
  • Backend Environment: Node.js with the Express.js framework for handling application routing and middleware.
  • External Integrations: OK.surf Free News API (JSON) and Bing News RSS Feeds via the rss-parser module.
  • Hosting / Deployment: Pre-configured for deployment on Render, featuring self-ping algorithms to maintain high availability.

3. Application Architecture

3.1 Frontend Design & Performance

The client-side interface is encapsulated in the frontend/ directory. It follows modular React component architecture (like the centralized Dashboard.jsx). The UI uses a premium SaaS aesthetic—focusing on diffused shadows, pristine white layouts, and modern typography (inter/system fonts), moving away from default sterile utility frameworks towards a handcrafted stylesheet. All images utilize automatic fallbacks to ensure the UI does not break on ad-blocker or scraping-protection interceptions.

3.2 Backend Service Layer

The unified server in the backend/ folder acts as an orchestration API wrapper. Rather than exposing external APIs and API keys directly to the frontend client, the Express server securely handles fetching operations. It consolidates heterogeneous data sources (e.g., standardizing JSON feeds and parsed RSS feeds) into a single, predictable structure for the React frontend, handling endpoints like /api/news/bfsi and /api/news/icici.

Implementation Highlight: The Stale-While-Revalidate Pattern
To protect against aggressive rate-limiting from external APIs and to ensure sub-millisecond response times, the backend implements an advanced caching mechanism. When a request hits the routing layer, the server immediately returns the cached snapshot (valid for 5 minutes). Simultaneously, it fires a background asynchronous process to fetch the newest data from the source without forcing the end-user to wait for the HTTP handshake.

4. Key Features & Accomplishments

  • Live Multi-Channel Aggregation: Merges general macro-finance data (BFSI, Markets, Commodities) directly via the OK.surf REST API payload extraction.
  • Targeted Feed Extraction: Implemented rss-parser to hijack and format the Bing News RSS feed specifically for "ICICI Bank," giving the application a deeply relevant localized data feed.
  • Mock AI Summarization: Deployed a /api/summarize endpoint built with structured faux delay to act as an integration point for future Natural Language Processing capabilities (like Gemini or OpenAI), showcasing readiness for generative AI features.
  • Production Auto-Wake Mechanism: Engineered an intelligent interval loop (setInterval at 14 minutes) where the Node server programmatically pings its own /api/health endpoint to circumvent "Free Tier Sleep" restrictions common in cloud hosts like Render.
  • Single Command Build Process: Setup synchronized package.json scripts enabling single-command full-stack installations and builds (e.g., executing client build injection into the Express static folder).

5. Conclusion

This dashboard serves as a highly robust proof-of-concept for internal corporate tooling. Through diligent separation of concerns between an aggressive backend proxy-cache and a sleek, reactive frontend UI, the application completely minimizes load times and elegantly handles network failures, providing an enterprise-tier data presentation layout ready for further data science enhancements.
